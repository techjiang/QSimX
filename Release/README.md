# QSimX Release v0.1.0

Linux x86_64 可运行包与验证记录。

- `qsimx-v0.1.0-linux-x86_64.tar.gz`
- `qsimx-v0.1.0-linux-x86_64.tar.gz.sha256`
- `VERIFICATION.txt`：真实测试与 CLI 输出
- `qsimx_release_verification.png`：验证截图

解压后运行：

```bash
tar -xzf qsimx-v0.1.0-linux-x86_64.tar.gz
./qsimx-cli bell 16
./qsimx-cli verify-m2-spectrum 3
```
